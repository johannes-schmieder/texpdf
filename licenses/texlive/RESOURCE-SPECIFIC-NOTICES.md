# Resource-specific TeX and font notices

This file preserves notices that are not represented by a single standard
SPDX license text. The generated resource attribution manifest binds each
notice to the exact embedded filename and SHA-256.

Copyright 2001, 2009, 2013 American Mathematical Society.

For `amsfonts.sty`, `amssymb.sty`, `umsa.fd`, and `umsb.fd`, the exact file
headers state:

> Unlimited copying and redistribution of this file are permitted as long as
> this file is not modified. Modifications, and distribution of modified
> versions, are permitted, but only if the resulting file is renamed.

The bundled AMS Type 1 font programs and related font data are separately
covered by the AMSFonts OFL notice, including its Reserved Font Names, in
`OFL-AMSFonts.txt`.

## Knuth-restricted resources

The Computer Modern metrics and related Knuth-originated resources retain the
TeX Live catalogue's `knuth` classification. They are redistributed unchanged.
The exact `hyphen.tex` header states:

> Unlimited copying and redistribution of this file are permitted as long as
> this file is not modified. Modifications are permitted, but only if the
> resulting file is not named hyphen.tex.

The same unchanged-file/rename-on-modification boundary applies to the other
Knuth-classified resources according to their upstream package notices. See
<https://tug.org/texlive/copying.html>.

## TeX Live generated map aggregates

`kanjix.map` and `pdftex.map` identify themselves as files generated by
`updmap`. They are redistributed unchanged from the pinned
`tlextras-2022.0r0` archive. `LicenseRef-TeXLive-Generated-Map` records that
these aggregates are generated from the separately inventoried, freely
redistributable map and font inputs; it does not replace or relicense those
component works. The governing collection policy is TeX Live's copying notice:
